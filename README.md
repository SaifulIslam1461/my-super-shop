# ROVIX™ E-Commerce & Admin Panel

এই প্রজেক্টটি **ROVIX™** লেদার ব্র্যান্ডের জন্য তৈরি একটি সম্পূর্ণ ফুল-স্ট্যাক ই-কমার্স ওয়েব অ্যাপ্লিকেশন।

## ফাইল তালিকা
- `index.html`: মূল স্টোরফন্ট।
- `admin.html`: অ্যাডমিন ড্যাশবোর্ড ও লগইন।
- `admin.css`: অ্যাডমিন স্টাইল।
- `admin.js`: অ্যাডমিন কার্যকারিতা ও ডাটাবেস অপারেশন।
- `products.js`: Supabase কানেকশন ও ডেটা হ্যান্ডলার।
